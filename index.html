How to Use on Phone & Laptop

To use this My Works app on both your laptop and mobile phone seamlessly:

Option A: Host Free on GitHub / Netlify (Recommended)
Upload this file (`index.html`) to GitHub Pages or Netlify for a free personal link (e.g. myworks.netlify.app) that you can open on both phone and laptop.
Option B: Save on Google Drive / OneDrive
Save this HTML file in your cloud folder. Open it directly on laptop or mobile browser.
Mobile Tip
In your mobile browser (Chrome or Safari), tap "Add to Home Screen" to create a quick app icon for 1-tap access on site!
