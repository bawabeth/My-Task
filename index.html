5-Minute Free Setup Guide:

  1. Go to Firebase Console and click Create a project.
  2. Click the Web (</>) icon to register a web app and copy the const firebaseConfig values.
  3. In the side panel, go to Build > Realtime Database $\rightarrow$ Click Create Database.
  4. Choose Start in Test Mode (allows read/write) and enable it.
  5. Paste the keys above and save! Your laptop and mobile are now synced in real time.
